以后你想提交新版本，操作步骤非常简单。通常只需要记住这**三个步骤（或者三个命令）**：

### 第一步：把修改告诉 Git（添加文件）
当你修改了项目里的代码，或者加了新文件，首先得告诉 Git：“注意啦，我要准备提交这些文件了”。
在黑框框里输入并回车：
`git add .`
*(注意 `add` 后面有一个空格和一个英文的点 `.`，意思是把你所有改过的文件都选上)*

### 第二步：写个提交说明（保存存档）
相当于给这个版本打个标签，写个小纸条说明这次更新了什么内容。
输入并回车（引号里写你的更新说明）：
`git commit -m "这里写你这次更新了哪些功能或修复了哪些bug"`

### 第三步：推到云端（上传到 Gitee）
把刚刚在本地保存好的版本，上传到你 Gitee 的仓库里。
输入并回车：
`git push`

---

**总结一下以后你的日常循环：**
改完代码 -> 输入 `git add .` -> 输入 `git commit -m "说明"` -> 输入 `git push`。

而且因为你现在已经成功用令牌登录过一次了，以后每次输入 `git push` 时，系统会自动记住你的身份，直接上传，不会再问你账号密码了！
