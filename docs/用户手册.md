## 一、产品简介

### 1.1 产品概述

云律 AI 是一款"**懂情绪**"的 Web 音乐播放器。它不只播放音乐，还能：

- 听懂你的一句话心情，**AI 帮你挑歌**；
- 根据歌曲情绪渲染**全屏氛围背景**；
- 把一句歌词变成一张**意境海报**；
- 汇总你的听歌习惯，生成**个人听歌报告**。

### 1.2 核心亮点

| 亮点 | 说明 |
|---|---|
| 🎵 AI 情绪点歌 | 输入「今天加班好累，想听点治愈的纯音乐」，AI 自动分析情绪并推荐歌曲 |
| 🌈 情绪氛围背景 | 播放时背景极光/星云随歌曲情绪流动变色，可一键开关 |
| 📊 实时数据大屏 | 独立的可视化大屏，展示播放趋势、24 小时分布、情绪构成 |
| 🖼 歌词海报 | 一句歌词 + 渐变配色，生成可下载的意境卡片 |
| 🎤 语音点歌 | 直接说「放一首舒缓的歌」就能播放 |
| 🎨 7 套主题换肤 | 蓝紫 / 网易云红 / 电光青 / 青柠绿 / 暖橙 / 玫瑰粉 / 黑金 |

### 1.3 运行环境

- **设备**：电脑（Windows/macOS/Linux）、平板、手机均可，通过浏览器访问
- **浏览器**：推荐 Chrome / Edge（完整支持语音识别、PWA 安装）；Firefox / Safari 基础功能可用
- **屏幕**：最佳体验分辨率 1280×720 以上；窄屏（手机）自动隐藏侧边栏，改为顶部导航

## 二、快速开始

### 2.1 启动服务

云律 AI 需要先启动后端服务才能访问：

1. 打开终端（命令提示符 / PowerShell），进入项目目录
2. 执行启动命令：

```bash
python manage.py runserver 0.0.0.0:8000
```

3. 看到 `Starting development server at http://0.0.0.0:8000/` 即启动成功
4. 打开浏览器访问 `http://127.0.0.1:8000/`

> 💡 小技巧：同一 Wi-Fi 下的其他设备可用 `http://电脑IP:8000` 访问，手机也能用。

### 2.2 首次访问与口令验证

首次进入页面需要输入访问口令（默认 **`yunlv888`**）：

1. 在口令输入框中输入口令
2. 点击「进入」按钮
3. 验证通过后 7 天内无需再次输入（浏览器自动记住）

> ⚠️ 若忘记口令，可在服务端 `settings.py` 的 `ACCESS_CODE` 中修改或置空（置空后关闭口令保护）。

### 2.3 页面总览

进入主界面后，左侧是**侧边栏导航**，包含 8 个板块入口 + 2 个设置按钮：

| 入口 | 功能 |
|---|---|
| 发现音乐 | 本地曲库 + 在线搜索 + 推荐 Banner |
| 每日推荐 | 根据听歌习惯智能推荐 |
| 情绪点歌台 | AI 情绪点歌（核心功能） |
| 我的歌单 | 自建歌单管理 |
| 我的收藏 | 收藏的歌曲 |
| 最近播放 | 播放历史 |
| 听歌报告 | 个人统计报告 + 排行榜 |
| 数据大屏 | 实时可视化大屏 |
| 换肤 | 切换 7 套主题色 |
| 动态背景 | 开关情绪氛围背景 |

页面底部是**播放器控制栏**，任何页面都可直接控制播放。

### 2.4 播放第一首歌

**方式一：播放本地歌曲**

1. 将 MP3 / FLAC / WAV / M4A / OGG 文件放入项目的 `music_library/` 目录
2. 回到「发现音乐」页面，点击右上角「重新扫描曲库」按钮
3. 扫描完成后歌曲出现在列表，点击封面或标题即可播放

**方式二：播放在线歌曲**

1. 在顶部搜索框输入歌名 / 歌手 / 专辑关键词，回车
2. 搜索结果同时包含本地与在线来源（iTunes / Jamendo / SoundHelix）
3. 点击任意在线歌曲即可试听或完整播放

**方式三：AI 点歌**

1. 进入「情绪点歌台」
2. 输入一句心情，如「想听点开心的歌」
3. 系统推荐歌曲后点击播放（详见第九章）

## 三、发现音乐

发现音乐是首页主板块，集中展示本地曲库、在线搜索和推荐内容。

### 3.1 本地曲库

- 点击「发现音乐」查看本地所有歌曲
- 列表展示：封面、歌曲名、歌手、专辑、情绪标签、时长
- 点击歌曲卡片右下角播放按钮立即播放

### 3.2 重新扫描曲库

- **入口**：页面右上角「重新扫描曲库」按钮
- **作用**：扫描 `music_library/` 目录新增的歌曲，自动读取标题 / 歌手 / 专辑 / 曲风信息
- 扫描入库的新歌会**自动进行 AI 情绪打标**（见第十章）
- 页面顶部会显示打标进度「新歌情绪标签生成中… 3/12」，完成后自动刷新

> 💡 小技巧：放入新歌后，刷新页面或点击「重新扫描」即可自动入库，无需重启服务。

### 3.3 在线搜索

顶部搜索框同时搜索**本地 + 三个在线源**，结果合并展示：

| 来源 | 说明 | 播放方式 |
|---|---|---|
| iTunes | 国际主流曲库 | 30 秒试听 |
| Jamendo | CC 授权音乐 | 完整播放 |
| SoundHelix | 无版权纯音乐 | 完整播放 |

搜索结果中每首歌都标注来源角标，方便区分。

### 3.4 推荐 Banner

- 页面顶部横幅随机展示一首曲库歌曲
- 提供「播放全部」和「随机播放」两个快捷入口
- 适合不知道听什么时一键开始

## 四、播放器核心

页面底部的播放器控制栏支持全部播放操作。

### 4.1 播放控制

- **播放 / 暂停**：点击中央播放按钮，或按键盘空格键
- **上一首 / 下一首**：点击两侧切歌按钮，或按 `←` / `→`
- **进度拖拽**：拖动进度条可快进/快退到任意位置；支持拖拽到未加载部分（Range 流）
- **音量调节**：拖动音量滑块调节，点击喇叭图标静音（或按 `M`）

### 4.2 播放模式

点击播放模式按钮循环切换三种模式：

| 模式 | 行为 |
|---|---|
| 顺序播放 | 列表按顺序播放，播完停止 |
| 列表循环 | 列表按顺序循环播放 |
| 随机播放 | 随机挑歌，播完继续随机 |

> 💡 键盘快捷键：按 `R` 快速切换播放模式。

### 4.3 频谱可视化

- 播放时底部频谱条实时跳动，随节奏起伏
- 点击频谱条区域可**收起 / 展开**，收起后界面更简洁

### 4.4 均衡器

- **入口**：播放器栏「均衡器」按钮
- **能力**：10 段频段独立调节
- **预设**：内置 摇滚 / 流行 / 低音 / 古典 等预设，一键套用
- 手动拖动频段滑块可自定义音效，自定义设置即时生效

### 4.5 定时关闭

- **入口**：播放器栏「定时」按钮
- **用法**：选择倒计时时长（如 15 / 30 / 60 分钟），到点自动暂停播放
- 适合睡前听歌场景

### 4.6 播放记忆

- 播放进度自动记录在本地
- 刷新页面或重新打开后，从上次断点位置继续播放
- 无需手动操作，打开即续听

### 4.7 媒体键控制

- 支持浏览器 Media Session：手机锁屏界面、系统媒体按键可直接控制播放 / 暂停 / 切歌
- 使用键盘多媒体键（播放/暂停、上一首、下一首）同样有效

### 4.8 情绪氛围背景

云律 AI 的特色视觉功能：

- **默认关闭**：页面为纯净的深色主题，文字对比度最高，适合长时间使用
- **开启方式**：点击侧边栏「动态背景」按钮，按钮高亮即开启
- **开启效果**：全屏极光/星云缓慢流动；换歌时背景色调随歌曲情绪平滑过渡；暂停时流速放缓、画面变暗
- **可读性保证**：背景叠加半透明深色罩，即使亮黄 / 亮绿等高亮情绪色下，文字依然清晰
- **记忆**：开关状态自动保存，下次打开保持上次的选择

> 💡 小技巧：投影演示或展示氛围效果时建议开启；日常听歌建议关闭以保持清爽与省电。

## 五、收藏与最近播放

### 5.1 收藏歌曲

- 每首歌卡片右上角有**心形按钮**，点击变红即收藏成功
- 再次点击取消收藏
- 键盘快捷键：播放中按 `F` 收藏 / 取消收藏当前歌曲
- 所有收藏在「我的收藏」板块统一展示

> ⚠️ 注意：收藏保存在当前浏览器的本地存储中，换浏览器 / 清理浏览器数据会清空收藏。

### 5.2 最近播放

- 播放过的歌曲自动记入「最近播放」，无需手动操作
- 每条记录显示歌曲信息与播放时间
- 点击记录可直接再次播放

## 六、歌单管理

### 6.1 创建歌单

1. 进入「我的歌单」
2. 点击「新建歌单」
3. 填写歌单名称、描述，可选上传封面图片
4. 点击创建，新歌单出现在列表中

### 6.2 添加歌曲

**方式一：歌单内添加**

1. 打开歌单进入详情页
2. 点击「添加歌曲」
3. 弹出搜索窗口，搜索本地或在线歌曲
4. 勾选歌曲点击确认加入

**方式二：右键快捷加入**

在任意歌曲卡片上右键，选择目标歌单一键加入（见 6.4）。

> 💡 同一首歌可同时存在于多个歌单；删除歌单不会删除歌曲本身。

### 6.3 歌曲排序与移除

- **排序**：在歌单详情页**拖拽歌曲行**即可调整顺序，松开自动保存
- **移除**：点击歌曲行的移除按钮，将歌曲移出当前歌单
- **删除歌单**：歌单卡片上的「删除」按钮，删除整个歌单（不影响歌曲）

### 6.4 右键快捷菜单

在任意歌曲卡片上**点击鼠标右键**弹出快捷菜单：

- 点击菜单外部、按 `Esc`、或滚动列表时自动关闭

## 七、歌词

### 7.1 歌词获取

云律 AI 自动为歌曲寻找歌词，无需手动导入：

1. **本地歌词**：曲库中与歌曲同名的 `.lrc` / `.txt` 歌词自动识别（兼容网易云 JSON 格式）
2. **在线抓取**：无本地歌词时自动在线抓取，**网易云 → lrclib** 两级兜底，成功后缓存到本地
3. 纯音乐或找不到歌词时，歌词面板显示友好提示

### 7.2 歌词同步显示

- 播放时歌词面板**逐行高亮**当前句，并自动居中滚动
- 点击歌词任意一行可跳转到对应时间点
- 歌词面板内可直接点击「生成歌词海报」（见第十二章）

### 7.3 歌词情绪曲线

播放时歌词面板顶部绘制**情绪色带 + 平滑曲线**：

- 每一句歌词都经过 AI 情绪分析（不可用时自动回退本地情绪关键词规则）
- 曲线上每个数据点按情绪着色，播放中当前句带发光游标与情绪标签
- 随着播放进度，游标实时推进——一眼看出整首歌的情绪起伏

> 💡 小技巧：打开一首有歌词的歌，歌词面板顶部的彩色曲线就是这首歌的"情绪心电图"。

## 八、每日推荐

- **入口**：侧边栏「每日推荐」
- **推荐依据**：分析最近 100 条听歌记录，按**标签重合度 + 曲风匹配**打分，推荐你未听过的歌
- **推荐理由**：每首歌都附「为什么推荐」说明，如「喜欢忧伤的歌、常听民谣」，让你知道推荐逻辑
- **兜底策略**：无听歌历史时，自动返回热门歌曲作为推荐

> 💡 使用建议：多听一段时间（超过 100 条记录）后推荐会越来越懂你。

## 九、AI 情绪点歌台

⭐ 云律 AI 的核心功能，把"找歌"变成"说心情"。

### 9.1 一句话点歌

1. 进入侧边栏「情绪点歌台」
2. 在输入框输入一句心情，例如：
   - 「今天加班好累，想听点治愈的纯音乐」
   - 「失恋了，想听伤感的歌」
   - 「跑步需要劲爆一点的」
3. 回车或点击发送
4. 系统分析情绪后返回推荐歌曲，自动载入播放队列，点击即播

匹配规则：情绪标签优先，曲风补充，逐级兜底；AI 服务不可用时自动降级为关键词规则匹配。

### 9.2 多轮对话追问

- 对推荐结果不满意，可以**继续追问**，例如「再欢快一点」「来点民谣」「不要那么悲伤」
- 对话上下文自动保留，AI 会根据你的补充调整推荐
- 无需重复描述原始心情

### 9.3 推荐理由与换一批

- 每首推荐歌曲都附有「为什么推荐」的说明文字
- 点「换一批」按钮可刷新推荐，获得不同组合

## 十、AI 歌曲情绪分类

云律 AI 会为本地歌曲自动识别情绪标签（如「开心」「难过」「放松」），这是情绪点歌准确的基础。

### 10.1 自动打标

- **触发时机**：点击「重新扫描曲库」后，后台自动对新歌逐首 AI 打标（约 1-2 秒/首）
- **进度查看**：页面顶部实时显示「新歌情绪标签生成中… 3/12」
- **完成**：打标完成后列表自动刷新，歌曲卡片展示情绪标签角标
- **原理**：读取歌曲歌词（本地优先，无则在线抓取）→ 交给 AI 分析 → 写入 12 种情绪标签中的 1-3 个

### 10.2 手动打标（了解）

歌曲标签可在数据库中手动调整；系统只处理空标签的新歌，**不会覆盖**手动调整过的标签。打标过程中断也无副作用，下次扫描自动补齐未完成的歌曲。

> 💡 标签越准确，情绪点歌台和每日推荐的匹配就越精准。

## 十一、语音点歌与快捷指令

### 11.1 语音点歌

1. 点击顶部麦克风按钮
2. 对着麦克风说出你的需求，例如「放一首舒缓的歌」「来一首周杰伦」
3. 系统自动识别并解析语义（支持歌手 / 情绪 / 曲风 / 随机等），返回匹配歌曲并自动播放

> ⚠️ 语音识别使用浏览器 Web Speech API，请允许浏览器使用麦克风权限；推荐在 Chrome / Edge 中使用。

### 11.2 快捷指令 chips

浏览器不支持语音或环境嘈杂时，可使用顶部**快捷指令 chips** 一键点歌：

| 指令 | 效果 |

## 十六、把云律装成 App（PWA）

云律 AI 支持安装为桌面 / 主屏应用，像原生 App 一样全屏使用。

### 16.1 安装方式

| 设备 | 操作 |

## 十七、常见问题 FAQ

**Q1：访问页面提示需要口令，口令是什么？**
默认口令为 `yunlv888`。可在服务端 `settings.py` 的 `ACCESS_CODE` 中修改或置空（置空后无需口令）。

**Q2：放入了歌曲文件，页面上却没有？**
点击「发现音乐」右上角「重新扫描曲库」，或刷新页面。确认文件格式为 MP3 / FLAC / WAV / M4A / OGG 之一。

**Q3：语音点歌没反应？**
确认浏览器允许麦克风权限，推荐使用 Chrome / Edge。仍不行时可使用顶部快捷指令 chips 兜底。

**Q4：情绪点歌推荐不准？**
推荐依赖歌曲的情绪标签。可先点击「重新扫描曲库」让系统对新歌完成 AI 打标，标签越准推荐越准；也可以在对话中追问细化需求（如「再欢快一点」）。

**Q5：背景太亮 / 看不清文字？**
点击侧边栏「动态背景」按钮关闭氛围背景即可回到深色主题。开启状态下背景已叠加深色罩保证文字可读。

**Q6：换了个浏览器，收藏和歌单不见了？**
收藏 / 最近播放 / 播放记忆 / 主题偏好保存在浏览器本地存储中，换浏览器或清理浏览器数据会丢失。歌单数据保存在服务器数据库中，不受影响。

**Q7：手机怎么访问？**
电脑与手机连同一 Wi-Fi，用 `http://电脑IP:8000` 访问（需口令）。

**Q8：在线歌曲只能试听 30 秒？**
iTunes 源为版权试听（30 秒）；Jamendo 与 SoundHelix 为 CC 授权音乐，可完整播放。
