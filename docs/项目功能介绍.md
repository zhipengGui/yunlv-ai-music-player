# 云律 AI · 项目功能介绍

> 一款"懂情绪"的 Web 音乐播放器。后端 Django + 前端原生 JS，覆盖本地/在线播放、歌单、歌词、推荐、AI 情绪点歌、语音点歌、海报、听歌报告等完整功能。

---

## 一、整体架构

```
浏览器(HTML+原生JS) ── HTTP/JSON ──> Django 后端
   │                                  ├── gate      访问口令
   │                                  ├── music     曲库/播放流/搜索/语音
   │                                  ├── playlists 歌单
   │                                  ├── lyrics    歌词(网易云/lrclib)
   │                                  ├── recommend 每日推荐
   │                                  ├── mood      AI 情绪点歌 + 歌曲情绪分类
   │                                  ├── posters   歌词海报
   │                                  └── report    听歌报告/排行榜
   │
   └── 第三方：智谱 GLM(情绪分析)、网易云/lrclib(歌词)、
       iTunes/Jamendo/SoundHelix(在线音乐)、Web Speech API(语音识别)
```

- 前端按模块拆分 JS 文件（播放器、歌词、情绪曲线、氛围背景、歌单、海报、报告、数据大屏、语音、频谱、均衡器、快捷键、主题换肤、帮助中心、设置面板、新手引导等）；样式通过 CSS 变量实现全局主题化
- 数据存储：歌曲/歌单/听歌记录 → SQLite；收藏/最近播放/播放记忆/主题偏好 → 浏览器 `localStorage`
- PWA：`manifest.webmanifest` + 全套尺寸图标，支持安装到桌面/主屏全屏运行

### 1. 访问口令（gate）

首次进入需输入口令（默认 `yunlv888`，在 `settings.py` 的 `ACCESS_CODE` 修改，置空则关闭）。通过后写入 session，7 天内免输入。所有页面与 API 都受中间件保护，适合分享给朋友时使用。

### 2. 发现音乐（板块1 · music）

- **本地曲库**：把 MP3/FLAC/WAV/M4A/OGG 放入 `music_library/`，点「重新扫描」或刷新页面自动入库，读取 ID3 元数据（标题/歌手/专辑/曲风）
- **在线搜索**：顶部搜索框同时搜本地 + 三个在线源，结果合并展示
  - iTunes：30 秒试听（免密钥）
  - Jamendo：CC 授权音乐，可完整播放（需配置 `JAMENDO_CLIENT_ID`）
  - SoundHelix：无版权纯音乐，完整播放
- **音频流**：本地文件与在线代理统一走 `/api/music/stream/<id>/`，支持 Range 拖拽
- 曲库为空时展示引导提示，附"重新扫描"按钮
- **推荐 Banner**：顶部横幅从曲库随机挑一首歌展示，附「播放全部」「随机播放」快捷入口

### 3. 播放器核心（player）

- 播放控制：播放/暂停、上一首/下一首、进度条拖拽、音量调节
- 三种播放模式：顺序、列表循环、随机（循环切换）
- **频谱可视化**：底部 Canvas 实时频谱动画，可收起
- **10 段均衡器**：预设 摇滚/流行/低音/古典 等，手动调节
- **定时关闭**：倒计时到点自动暂停
- **播放记忆**：播放进度本地记录，刷新/重新打开后从断点继续
- **Media Session**：浏览器锁屏/媒体键控制歌曲
- 封面自动生成：无封面歌曲用 Canvas 按标题/歌手生成渐变封面
- **全屏情绪氛围背景**：播放时全屏极光/星云缓慢流动，换歌时背景色调随歌曲情绪平滑过渡，暂停时流速放缓、画面变暗；纯 Canvas 绘制，零外部依赖
- **动态背景一键开关**：侧边栏「动态背景」按钮可随时开启/关闭氛围背景（状态存 localStorage 并持久化）。默认关闭——背景为纯深色主题，文字对比度最高；开启后背景随歌曲情绪流动变色，并叠加半透明深色罩压低情绪色亮度，即使亮黄/亮绿等高亮度情绪色下文字也保持清晰可读

### 4. 收藏与最近播放（favorites）

- 歌曲卡片右上角心形按钮 → 收藏到「我的收藏」（`localStorage`）
- 播放过的歌曲自动记入「最近播放」，显示播放时间
- 两个列表都支持直接点播

### 5. 歌单管理（板块3 · playlists）

- 创建歌单：名称 + 描述 + 封面（可上传图片）
- 歌单详情：歌曲表格（序号/标题/歌手/专辑/时长），支持单曲移除、列表删除歌单
- 添加歌曲：歌单内搜索弹窗，本地 + 在线歌曲均可加入
- 排序：歌单内歌曲可拖拽排序
- **允许一首歌同时存在于多个歌单**，删除歌单不影响歌曲本身

### 6. 右键快捷菜单（context-menu）

右键任意歌曲卡片弹出菜单：

```
▶ 播放
♥ 收藏/取消收藏
──────────────
加入歌单：
  [我的歌单列表]   ← 一键加入任意歌单
  ＋ 新建歌单
```

- 菜单自动跟随鼠标定位，超出视口自动翻转
- 点击外部 / 按 Esc / 滚动列表自动关闭

### 7. 歌词（板块4 · lyrics）

- 本地 `.lrc` / `.txt` 歌词自动识别（兼容网易云 JSON 格式）
- 无本地歌词时自动在线抓取：**网易云 → lrclib** 两级兜底，成功后缓存为 `.lrc` 文件
- 播放时逐行高亮 + 自动居中滚动，同步当前句
- **歌词情绪曲线**：歌词加载后把每一句文本发往后端 `/api/lyrics/analyze/` 逐句情绪分析（AI 失败自动回退本地 12 情绪关键词规则），在歌词面板顶部绘制「情绪色带 + 平滑曲线 + 情绪着色数据点」；播放时当前句带发光游标与顶部情绪标签，随播放进度实时推进
- 歌词面板内可直接「生成歌词海报」
- 纯音乐/无歌词时展示友好提示

### 8. 每日推荐（板块5 · recommend）

- 基于最近 100 条听歌记录的**标签重合度 + 曲风匹配**打分，推荐未听过的歌
- 每首歌附"为什么推荐"理由（如「喜欢忧伤的歌、常听民谣」）
- 无听歌历史时兜底返回热门歌曲

### 9. AI 情绪点歌台（板块6 · mood）⭐ 核心功能

- 顶部输入一句心情，如「今天加班好累，想听点治愈的纯音乐」
- 智谱 GLM 分析：输出情绪标签 + 曲风 + 推荐说明
- 按情绪标签优先匹配歌曲（曲风补充），逐级兜底，AI 不可用时自动用关键词规则
- 返回结果自动载入播放队列，点击即播

**已修复的匹配问题**：
- `emotions`（用户情绪）与 `tags`（歌曲氛围）合并参与查询，避免漏掉核心情绪
- 情绪标签优先、曲风仅补缺，避免 `genre=pop` 把伤感歌带进开心歌单
- 演示曲（无真实情绪）不参与情绪推荐

### 10. AI 歌曲情绪分类（retag_songs）⭐ 板块6 扩展

> 解决"本地歌被一刀切标成 happy"的历史问题。

- **原理**：读取歌词（本地 `.lrc` 优先，无则在线抓取）→ 将「歌名+歌手+歌词片段」交给智谱 GLM → 从 12 个情绪标签中选择 1-3 个写回数据库
- 无歌词 / AI 失败时用歌词关键词规则兜底（悲伤词优先，避免误标）
- 扫描入库时无曲风标签的歌曲**不再兜底成 pop→happy**，留空待 AI 判定

**扫描后自动打标（推荐）**：
- 点「重新扫描曲库」入库后，后台自动对新歌逐首 AI 打标（并发 2，约 1-2 秒/首），接口立即返回不阻塞
- 页面顶部实时显示进度「新歌情绪标签生成中… 3/12」，打标完成后自动刷新列表展示新标签
- 只打**空标签**的新歌，不影响手动调整过的标签；打标过程被打断也无副作用（未完成的歌保持空标签，下次扫描自动补齐）

**手动增量打标**：
- `python manage.py retag_songs --only-untagged`：只处理空标签歌曲（增量，无需全量重跑）
- `python manage.py retag_songs --ids 1,2,3`：只处理指定 id 的歌曲

情绪标签词表（12 个）：开心 happy / 难过 sad / 放松 relaxing / 充满活力 energetic / 平静 calm / 浪漫 romantic / 怀旧 nostalgic / 专注 focused / 疲惫 tired / 愤怒 angry / 孤独 lonely / 轻快 cheerful

### 11. 语音点歌（voice）

- 点「语音点歌」麦克风按钮，用 Web Speech API 识别中文语音，如「放一首舒缓的歌」
- 识别文本交给后端解析（支持歌手/情绪/曲风/随机等语义），返回匹配歌曲并自动播放
- 浏览器不支持语音时，可用顶部**快捷指令 chips**（🌿舒缓 / 😄欢快 / 🔥动感 / 🎤歌手 / 🎹钢琴 / 🎲随机）兜底

### 12. 歌词海报（板块7 · posters）

- 在歌词面板点「生成歌词海报」，Canvas 生成 600×800 意境卡片（当前歌词 + 歌曲信息 + 渐变配色）
- 支持「换个风格」切换配色、一键下载 PNG

### 13. 听歌报告 & 排行榜（板块8 · report）

- **听歌报告**：汇总你的播放统计（总时长、播放次数、最爱歌曲、情绪标签偏好等）
- **排行榜**：热门歌曲榜（按播放量）
- **实时数据大屏**（独立页面 `/dashboard/`，侧边栏「数据大屏」入口首次点击才懒加载 iframe）：Canvas 自绘「播放趋势 / 24 小时分布 / 情绪环形图」等图表，每 4 秒轮询 `/api/report/dashboard/`，播放中的歌曲实时增量更新并高亮；切换走再切回保留状态不重载
- 数据来源：播放时自动上报的 `ListenRecord`

### 14. 主题换肤（theme）⭐ 视觉定制

- 入口：左侧导航栏底部「换肤」按钮（衣服图标）
- **7 套预设主题**，通过 `<html data-theme="...">` 切换 CSS 变量（`--brand` / `--brand-grad`）实现全站换肤，无需改动组件：

| 主题 | data-theme | 主色 → 渐变 | 风格 |
|---|---|---|---|
| 云律蓝紫（默认） | `azure` | `#5b8cff → #a78bfa` | 与 PWA 图标一致，品牌统一 |
| 网易云红 | `netease` | `#ec4141 → #ff7e5f` | 经典音乐风 |
| 电光青 | `cyan` | `#3fd6ff → #6ee7ff` | 科技感 |
| 青柠绿 | `lime` | `#3ddc84 → #7ce38b` | 清爽 |
| 暖橙 | `amber` | `#ff8a3d → #ffb35c` | 温暖 |
| 玫瑰粉 | `rose` | `#f472b6 → #ff9ecf` | 柔和 |
| 黑金 | `gold` | `#d4af37 → #f5e08a` | 奢华 |

- 选择结果存 `localStorage`（`yunlu_theme`），启动时由 `<head>` 内联脚本提前恢复，避免首屏闪烁
- 换肤同时同步浏览器地址栏 / 移动端状态栏的 `theme-color`

### 15. PWA 安装（PWA）⭐ 变成"App"

- **清单**：`static/manifest.webmanifest`（名称「云律」、`standalone` 全屏显示、`theme_color`）
- **图标**：`static/img/icons/` 下 6 个文件——`icon-192x192` / `icon-512x512`（manifest）、`icon-180x180`（Apple 触摸图标）、`icon-maskable-192x192` / `icon-maskable-512x512`（Android 自适应）、`favicon-32x32`
- **安装方式**：
  - 电脑 Chrome/Edge：地址栏右侧「安装」图标 → 桌面出现「云律」
  - iOS Safari：分享 →「添加到主屏幕」
  - 安卓 Chrome：菜单 →「安装应用」
- **前提**：PWA 安装要求 **HTTPS**（`localhost` 除外），外网分享需用 HTTPS 穿透域名
- **注意**：目前为"轻量 PWA"（有清单/图标/独立窗口，无 Service Worker），安装后内容仍实时从服务器拉取，不支持离线缓存

### 16. 键盘快捷键（shortcuts）⭐ 桌面端体验

全局监听 `keydown`（`static/js/shortcuts.js`），播放控制与快捷操作一手搞定；**输入框/编辑区聚焦时自动停用**（避免干扰打字），仅 `Esc` 例外用于取消聚焦。

| 按键 | 功能 |
|---|---|
| 空格 | 播放 / 暂停 |
| ← / → | 上一首 / 下一首 |
| ↑ / ↓ | 音量 +10% / −10% |
| M | 静音 / 取消静音（取消时恢复原音量） |
| [ / ] | 快退 / 快进 10 秒 |
| R | 切换播放模式（顺序 / 循环 / 随机） |
| F | 收藏 / 取消收藏当前歌曲 |
| / 或 Ctrl/Meta + K | 聚焦搜索框 |
| Ctrl/Meta + L | 聚焦 AI 点歌输入框 |
| 1 ~ 7 | 切换侧边栏板块（发现/推荐/情绪/歌单/收藏/最近/报告） |
| ? 或 Shift+/ | 打开快捷键帮助面板 |
| Esc | 关闭帮助面板 / 取消输入框聚焦 |

- 数字键 `1~7` 与侧边栏板块一一对应（`1` 发现 → `7` 报告）
- 按 `?` 可随时打开页面内置的帮助面板（`#shortcut-modal`），点击遮罩或 `Esc` 关闭
- 其余带修饰键的组合一律不响应，避免误触

### 17. 帮助中心 · 设置面板 · 新手引导（help / settings / onboard）⭐ 新手上路

> 在侧边栏「动态背景」下方新增「帮助」「设置」两项入口，把分散的教程与偏好收拢成三个互通的入口：首次自动引导 → 帮助中心完整教程 → 设置面板集中偏好。

- **帮助中心（`help-modal`）**：随时可重复打开，内含 3 个 Tab
  - 新手必看：本地曲库放入 `music_library/` 并重新扫描、在线试听说明、AI 点歌可继续追问、语音点歌浏览器要求
  - 隐藏玩法：歌曲右键菜单 / 歌单拖拽排序 / 歌词海报 / 均衡器与定时 / 听歌报告与数据大屏等进阶技巧
  - 关于云律：项目定位、功能标签与本地隐私说明
  - 底部提供「键盘快捷键」（直接跳转快捷键面板，内容单一来源）与「重新播放新手引导」
- **设置面板（`settings-modal`）**：把散落在各功能的已有偏好集中成一屏，**全部复用原有 localStorage 键，零新增存储逻辑**，与对应功能实时联动：
  - 主题配色（7 色圆点，与「换肤」面板同步）
  - 动态氛围背景开关（`AmbientBG`）
  - 均衡器预设（7 档，`EQ`）
  - 播放模式（顺序 / 单曲循环 / 随机，直接切换并持久化）
  - 频谱条默认展开开关（`SpectrumBar`）
  - 新手引导「重新播放」
- **首次引导气泡（`onboard`）**：页面就绪后自动弹出 3 步聚光灯引导（高亮 AI 点歌输入框 → 语音点歌 → 底部播放条功能区），气泡跟随元素定位、放不下自动翻向；跳过或走完即写入 `yunlu.onboard.done` 标记，之后不再自动打扰；需要复习时在「帮助 / 设置」里点「重新播放新手引导」即可重新走一遍
- 窄屏（≤ 900px，侧边栏隐藏）自动跳过引导，移动端不受影响

## 七、部署与分享

### 局域网

```bash
python manage.py runserver 0.0.0.0:8000
```

同一 Wi-Fi 下用 `http://电脑IP:8000` 访问（需访问口令）。

### 外网（花生壳 HTTPS 内网穿透）

1. 花生壳添加 **HTTPS 映射**，目标地址 `127.0.0.1:8000`
2. `python manage.py runserver 0.0.0.0:8000`
3. 把 `https://你的域名` 发给朋友，输入口令即可使用

已内置适配：`ALLOWED_HOSTS=["*"]`、`SECURE_PROXY_SSL_HEADER`、`CSRF_TRUSTED_ORIGINS`（花生壳域名通配），更换花生壳域名无需改配置。

### 远程加速：静态资源上云（对象存储 CDN）

> **本项目实际部署使用阿里云 OSS**（成都地域，bucket `yunlv888`；`tools/cloud_config.json` 同时兼容腾讯云 COS / 七牛，改 `provider` 即可切换，与花生壳穿透互补——穿透解决"可达"，OSS 解决"快"）。

> 背景：远程用户经花生壳 HTTPS 隧道访问时，页面 JS/CSS/封面图原本都从自建服务器下载，首次打开较慢。本功能把静态资源上传到与音频相同的对象存储（OSS/COS/七牛）桶，页面 JS/CSS/图标/歌曲封面直接从对象存储域名加载，远程首屏打开与切歌同速。

- **一键上传**：`python manage.py upload_statics`（`static/` 与 `media/` 封面全部上传，幂等可重复执行；`--dry-run` 只预览清单 / `--force` 强制覆盖已存在封面 / `--only media` 只传封面）
- **开启**：`tools/cloud_config.json` → `static_cdn.enabled = true`（`base` 留空自动使用对象存储 `public_domain`），保存后重启服务生效
- **回滚**：把 `enabled` 置 `false`，或设置环境变量 `CLOUD_STATIC_BASE=off`，重启服务即回到本地加载，无需改代码
- **缓存与更新**：所有静态引用带版本号（`?v=文件修改时间`），static 资源长缓存一年、封面缓存 1 小时；本地改动静态文件后重跑一次 `upload_statics` 即可，版本号自动变化、浏览器自动拉取新文件，无需手动清缓存

### PWA 安装条件

- HTTPS 或 `localhost` 才允许安装；http 局域网地址仅供网页使用
- 安装后内容仍实时从服务器拉取（未加 Service Worker，无离线缓存）

## 八、开源仓库与二次运行说明

项目源码已开源（MIT 协议）。出于体积、版权与密钥安全考虑，以下内容**不入库**，克隆后需自行准备：

| 未入库内容 | 原因 | 如何处理 |
|---|---|---|
| `music_library/`（MP3/FLAC/LRC，3GB+） | 体积过大且涉及音乐版权 | 放入自己的音乐文件后刷新页面自动扫描入库；不放也能正常使用「在线曲库」 |
| `media/`（歌曲封面图） | 运行时自动生成 | 扫描曲库时自动抓取生成，无需手动处理 |
| `tools/cloud_config.json`（对象存储密钥） | 含真实 AccessKey，禁止提交 | 复制 `tools/cloud_config.example.json` 为 `tools/cloud_config.json` 后填入自己的密钥 |
| `云律AI交付包/`、各类压缩包 | 与仓库源码重复的打包副本 | 无需处理 |

**二次运行三步**：

1. `pip install -r requirements.txt`
2. 设置环境变量 `DJANGO_SECRET_KEY`（部署必做）、`ZHIPU_API_KEY`（AI 功能，可选）
3. `python manage.py migrate` 后 `python manage.py runserver 8000`

> 变更说明：`cloud_music/settings.py` 的 `SECRET_KEY` 已由"写死真实值"改为读取环境变量 `DJANGO_SECRET_KEY`，未设置时回退到占位值，仅供本地开发使用。
